关于 CyberOrion

跨域协同自主闭环网络安全超级智能体——统一智能体架构覆盖多域安全场景，每个子域自主推理、自主闭环。

项目愿景

传统安全工具各自为战，检测与响应割裂。CyberOrion 以统一的智能体编排架构，将钓鱼邮件检测、红蓝对抗、威胁情报关联等安全子域串联为跨域协同的闭环体系。每个子域由专业 Agent 团队自主推理、自主决策，编排器统一调度，最终给出可解释、可追溯的安全研判。

子项目

钓鱼邮件检测引擎：多 Agent 协同编排，覆盖发件人画像、邮件头取证、语义意图、URL/附件检测、威胁情报关联与风险融合，SSE 实时推送全过程。

红蓝对抗平台：红方 Agent 自主渗透 Docker 靶场，蓝方 SOC 团队信息隔离防守，服务端裁判客观评分（TP/FP/FN/检测率/MTTD），可复现可审计的 LLM 攻防。

技术栈
FastAPI Server-Sent Events OpenAI-Compatible LLM Docker 靶场 CAI Framework 知识库 RAG ATT&CK 映射 自注册工具集
设计理念

跨域协同：不同安全子域的 Agent 共享编排层与知识库，证据跨域流通。

自主闭环：从检测到处置，Agent 自主推理决策，减少人工干预。

透明可审计：每一步推理、工具调用、证据都可追溯，过程实时可见。
