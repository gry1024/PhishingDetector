关于 PhishingDetector

面向企业邮箱场景的 AI 钓鱼邮件检测编排系统，让每一封可疑邮件的研判过程都透明、可追溯、可解释。

项目背景

传统邮件安全网关依赖黑名单与规则，难以应对快速演变的社工话术、AI 生成内容和零日钓鱼域名。PhishingDetector 通过多 Agent 协同推理，将发件人画像、邮件头取证、语义意图、URL/附件技术检测、威胁情报关联与风险融合串联成一条可执行的证据链，最终给出定量评分与可落地的处置建议。

技术栈

FastAPI Uvicorn Server-Sent Events OpenAI-Compatible LLM Pydantic SQLite 纯前端 SSE 渲染 自注册工具集

设计理念

透明：用户不仅能看到最终风险分，还能看到每个 Agent 的推理、每一步子步骤与证据。

鲁棒：当 LLM 不可用时，内置规则兜底机制仍可完成基础检测，保证服务可用性。

可扩展：工具通过装饰器自注册，新增 Agent 或工具无需改动编排器核心逻辑。

核心能力

Orchestrator 驱动的 7 个专业子 Agent 协同工作，覆盖从发件人到响应建议的完整检测链路。

🕵️ 发件人画像

分析发件人域名信誉、Display Name 冒充、历史出现频率与组织一致性，识别伪造身份。

🔍 邮件头取证

提取 SPF、DKIM、DMARC 等认证结果，检测路由异常、时间戳伪造与邮件转发痕迹。

🧠 语义意图

理解邮件主题与正文的社会工程话术，识别 urgency、权威冒充、奖励诱导等意图。

🛰️ 威胁情报关联

自动提取 IOC，匹配已知钓鱼模式，必要时联网检索公开情报，并映射到 MITRE ATT&CK。

🛡️ 技术检测

静态分析 URL、域名、附件名与行为异常，发现 IP 直链、短链、可疑 TLD 等技术指标。

⚖️ 风险融合

综合多维度证据，通过加权算法给出 0-100 的量化风险分，并解释关键证据。

📝 响应建议

根据风险等级生成可执行建议：隔离、深度研判、员工提醒、自动报告等。

📡 实时推送

基于 SSE 的流式输出，Agent 调用、子步骤、工具结果即时呈现在前端，无需轮询。

检测证据链

每封邮件进入系统后，Orchestrator 首先进行多假设推理与策略规划，随后依次调用相关子 Agent。每个 Agent 在 LLM 推理与本地规则之间自动选择，并将结果以结构化事件流推送到前端。最终报告聚合所有证据、评分与 ATT&CK 映射，支持一键导出。
